# Moodboard

Drop 10 to 20 reference images here: places, films, posters, products, photos,
anything that has the feeling you want. Name them by what you like about them,
e.g. `warm-lamp-light-on-wood.jpg`, `arcade-cabinet-bezel.jpg`.

Agents read this folder when asked about taste. Add a line per image below if
the file name is not enough.
