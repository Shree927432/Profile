# Moodboard

Drop 10 to 20 reference images here: places, films, posters, products, photos,
anything that has the feeling you want. Name them by what you like about them,
e.g. `warm-lamp-light-on-wood.jpg`, `arcade-cabinet-bezel.jpg`.

Agents read this folder when asked about taste. Add a line per image below if
the file name is not enough.

Photos found on the web go in `local/`, which git ignores, because they are not
ours to publish in a public repo. Our own sketches and photos go here.

- `local/chosen-room-guitar-wall-bedroom-studio.jpg` (local only): the room the
  owner chose on 2026-10-19. Bed, bookshelf with frames, window with a plant,
  desk with monitor, speakers and a mic arm, acoustic panels, a wall of guitars.
  We swap its digital piano for an upright.
- `room-sketch.html`: our sketch of that room with the upright piano.
- `premise-sketches.html`: the three earlier options (A, B, C), kept for reference.
