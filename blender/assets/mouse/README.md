# MX Master 3S shell

`mx-master-3s-shell.json` is our own quad shell for the mouse, wrapped onto a 3D scan by
`blender/components/mouse_scan.py`. It is derived from "Logitech MX Master 3S - Revopoint Mini 3D Scan" by
Sircher, licensed CC BY 4.0:
https://sketchfab.com/3d-models/logitech-mx-master-3s-revopoint-mini-3d-scan-9a82df69ffee4c6faa28f75e65ba192c
The scan itself stays local (docs/moodboard/local/ai-lab/23-mouse/scan/) and is never shipped.
