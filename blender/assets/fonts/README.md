# Fonts for the invented brand names

Static weights cut from Google Fonts' official files (github.com/google/fonts, downloaded 2026-10-26) with
fontTools' instancer. Each is under the SIL Open Font License; the licence for each family sits beside it
(`OFL-<family>.txt`). Used only inside Blender: the letters become part of the 3D models, so the site never
loads these files. Which name uses which font: `content/room-brands.json`.

| File | From | Weight |
|---|---|---|
| Montserrat-SemiBold.ttf | Montserrat[wght].ttf | 600 |
| RobotoCondensed-Bold.ttf | RobotoCondensed[wght].ttf | 700 |
| Rokkitt-Bold.ttf | Rokkitt[wght].ttf | 700 |
| Rajdhani-Bold.ttf | Rajdhani-Bold.ttf (static already) | 700 |
| Saira-ExtraBoldItalic.ttf | Saira-Italic[wdth,wght].ttf | 800, width 100 |
| LibreCaslonText-Bold.ttf | LibreCaslonText[wght].ttf | 700 |
| Comfortaa-Bold.ttf | Comfortaa[wght].ttf | 700 |
